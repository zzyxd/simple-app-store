# Simple App Store

A tiny Android app built with Kotlin + Jetpack Compose.

## Features
- Search bar
- App cards
- Open-source app listing inspired by the F-Droid archive
- Tap an app to open a browser link

## How to run
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run the `app` configuration on an emulator or Android device.

## Notes
This is intentionally simple and static. It works as a clean starting point for a real app store app.

## App data source
The current app uses a built-in list of sample apps, with links pointing to the F-Droid archive page.

## Android versions
- Minimum SDK: 24
- Target SDK: 34
